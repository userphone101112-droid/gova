# ADR-0004: Centralize All Documentation in docs/ Directory

**Date**: 2026-06-12
**Status**: Accepted
**Deciders**: Platform Architecture Team

---

## Context

Documentation was fragmented across multiple locations:

- `src/docs/` (architecture, coding-standards, development-guide)
- `docs/` (SSOT system docs)
- `apps/api/` (backend README)
- Root level (README, AGENTS, DEPLOY_KEY_SETUP, CLAUDE)

This caused discovery friction, outdated references, and no single source of truth for project knowledge.

## Decision

**All documentation MUST reside under `docs/`** following the governance structure defined in `docs/governance/file-placement-rules.md`.

**Allowed exceptions** (enforced by governance rules):

1. `README.md` — Repository root only (entry point redirect to `docs/`)
2. `AGENTS.md` — Repository root only (AI tooling configuration, never documentation)
3. `CHANGELOG.md` — Repository root only, auto-generated from `docs/changelogs/`

**Prohibited**:

- `.md` or `.mdx` files in `src/`, `apps/`, `packages/`, or any subdirectory

## Migration

| File                            | Action          | Destination                            |
| ------------------------------- | --------------- | -------------------------------------- |
| `src/docs/architecture.md`      | Moved → merged  | `docs/architecture/system-overview.md` |
| `src/docs/development-guide.md` | Moved           | `docs/development/getting-started.md`  |
| `src/docs/coding-standards.md`  | Moved           | `docs/development/coding-standards.md` |
| `apps/api/README.md`            | Moved → merged  | `docs/modules/backend-api.md`          |
| `DEPLOY_KEY_SETUP.md`           | Moved           | `docs/deployment/deploy-key-setup.md`  |
| `CLAUDE.md`                     | Deleted (empty) | —                                      |

## Consequences

**Positive:**

- One place to look for all project knowledge
- AI agents get clean context from `docs/ai-context/`
- Automated enforcement prevents documentation sprawl
- Contributors follow clear governance rules

**Negative:**

- `apps/api/README.md` loses conventional discoverability in GitHub UI
- Requires migration of all existing docs (done in this ADR)
