# ADR-0003: Use Drizzle ORM with SQLite/Turso Adapter

**Date**: 2026-06-01
**Status**: Accepted
**Deciders**: Platform Architecture Team

---

## Context

Needed an ORM that supports both local development (SQLite) and production (distributed Turso/LibSQL) without code changes.

## Decision

Use **Drizzle ORM** with an adapter pattern that switches between `better-sqlite3` (local) and `@libsql/client` (Turso) based on `DATABASE_PROVIDER` environment variable.

## Consequences

**Positive:**

- Single schema definition works for both providers
- Type-safe queries with full TypeScript support
- Lightweight — no heavy ORM overhead
- Turso enables global edge database distribution

**Negative:**

- Drizzle is relatively new — smaller community than Prisma
- Some advanced query patterns require raw SQL

## Implementation

- Schema: `apps/api/src/infrastructure/database/schema/`
- Adapter: `apps/api/src/infrastructure/database/adapters/`
- Repositories: `apps/api/src/infrastructure/database/repositories/`
- Config: `@gv/config` → `backendEnvSchema.DATABASE_PROVIDER`
